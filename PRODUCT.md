# Product

## Platform
web
## Stack
React/Vite, FastAPI and MongoDB. Local Windows agency workspace.
## Users
Agency staff preparing and reviewing visa applications and their supporting documents.
## Product Purpose
Manage applicants, evidence, country/visa requirements, reproducible evidence assessments and reviewed statistical models.
## Constraints
Retain routes, authentication, private storage, decimal calculations, document provenance and report history. Evidence strength is separate from approval probability. Never invent outcomes or official policies.
## Design request
User authorized an entire-system redesign: remove emoji, redundant text, decorative icons and inconsistent fonts. Keep requirement editing to name and points. Earlier project templates are the benchmark; exact project reference is pending an asynchronous question. The prior ABA reader is available locally as an initial reference.
